절차적 지형 생성 시스템, 듀얼 버퍼 타일링, 10단계 스카이 셰이더 구현

X/Z 평면 2D 충돌과 Y축 높이 조건을 분리한 독립 물리 판정 로직 구현

rAF 기반 60fps 포물선 궤적 애니메이션, 도착 시 점수판 펄스 효과 구현
성능 최적화

GC 유발 스프레드 연산자 제거, DOM 리플로우 최소화로 60fps 안정화

"화면 위에 레이스 현재 위치 현황을 넣을 거야. 캐릭터를 조그맣게 옆모습으로 추가해서 왼쪽에서 오른쪽으로 이동하고, 스테이지 깃발 위치를 비율에 맞게 꽂아줘."

아키텍처 설계
모듈 분리(ui.js·main.js·medalAnimation.js 등) 및 성능 최적화 구조를 AI와 협업하여 체계적으로 구성
💡  AI 활용 방식

프롬프트 전략

  • 원하는 게임 느낌을 자연어로 먼저 설명
  • 버그 발생 시 증상 중심으로 묘사
  • 수정 후 직접 플레이 테스트 → 재피드백 반복
  • 세부 수치는 "살짝", "조금 더" 등 감각적 표현 활용

협업 방식

  • AI가 코드 초안 생성 → 개발자가 플레이 검증
  • 복잡한 변경은 AI의 구현 계획 검토 후 승인
  • 여러 파일 동시 수정 시 AI가 의존성 자동 파악
  • 서버 실행·브라우저 테스트까지 AI가 직접 수행
