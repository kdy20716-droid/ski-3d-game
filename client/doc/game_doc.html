🎮  게임 개요

SNOWFALL은 눈 덮인 설산을 배경으로 한 웹 기반 3D 알파인 스키 게임입니다.
플레이어는 뒤에서 쏟아지는 산사태를 피해 경사를 내려가며, 다이아몬드와 메달을 수집해 점수를 쌓습니다.
새벽부터 오로라 밤까지 10개의 스테이지를 거치며 환경이 실시간으로 전환되는 것이 핵심 콘셉트입니다.

장르 & 플랫폼

  • 장르: 무한 러너 · 스키 액션
  • 플랫폼: 웹 브라우저 (PC)
  • 렌더링: Three.js 3D (WebGL)
  • 서버: Node.js · Python HTTP

핵심 목표

  • 산사태에 잡히지 않고 생존
  • 10스테이지 완주 (총 약 15km)
  • 메달 · 다이아몬드 최대 수집
  • 드리프트 & 점프 콤보 점수 극대화

ESC일시정지 / 재개

게임 흐름

  • 게임 시작 시 오프닝 컷씬이 재생되고, 즉시 산사태가 따라옵니다.
  • 다이아몬드 아치 게이트를 통과하면 점수 획득. 색상이 밝을수록 고점수입니다.
  • 스테이지 중 메달 점프대(★)에서 메달을 최대 3개까지 수집할 수 있습니다.
  • 관문(깃발 게이트)을 통과하면 다음 스테이지로 전환되며, 수집한 메달이 점수판으로 날아가 보너스 점수가 지급됩니다.
  • 나무에 충돌하면 속도가 0이 되고 5초 무적 상태로 리스폰됩니다.
  • 산사태에 따라잡히면 게임 오버. 10스테이지 완주가 최종 목표입니다.
🔧  주요 시스템

드리프트 시스템

SHIFT + 방향키로 드리프트 게이지를 충전하면 게이지가 가득 찰 때 순간 부스터가 발동됩니다.

점프 시스템

SPACE 홀드 시간에 따라 점프 높이가 결정됩니다. 눈덩이 장애물을 밟으면 바운스 점프가 가능합니다.

메달 수집

각 스테이지에 메달 점프대 3개가 배치됩니다. 관문 통과 시 보너스 점수(+3,000 / +6,000 / +10,000)로 전환됩니다.

레이스 진행도 UI

상단 바에 현재 위치와 스테이지 깃발이 표시됩니다. 🎿 아이콘이 실시간으로 이동하며 최종 도착점은 체커보드로 표시됩니다.
